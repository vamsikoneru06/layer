# P1 · M2 — Editor: fonts, export, text editing, properties, photos, filters

**Spec:** §7 (engine: text, filters, images, export), §10 (editor UI), §11.1 (budgets). Brief §6.12 (editor states and panels).
**Branch:** `feat/editor-m2` (stacked on `main` after #12). Each task ends green and committed.

## Tasks
1. [x] **Fonts** — self-host the 20 allowlisted families (`pnpm fonts:sync`), load a document's fonts via `document.fonts`, re-measure on arrival.
2. [x] **PNG export** — engine `exportPng(doc, { scale, transparent })` on an OffscreenCanvas at 1×/2×/3×, awaits fonts,
       8192 px cap with a friendly error; Export popover (size with pixel dimensions, transparent toggle, Download → Rendering… → Downloaded).
3. [x] **Text editing on canvas** — double-click (or Enter) a text layer: a `<textarea>` positioned by CSS `matrix()` over the layer,
       same font/size/colour/alignment; commits one undo step; Escape cancels; respects `maxChars` and content-only locks.
4. [x] **Properties panel** — nothing selected: artboard size and background colour; any layer: X/Y/W/H/rotation/opacity;
       text: font (allowlist, live previews), weight, size, colour, alignment, line height, letter spacing, shrink-to-fit;
       shape: fill and stroke; lock state with unlock. Numeric fields are tabular, Enter/blur commits one undo step.
5. [ ] **Photos** (needs Supabase Storage keys) — resolve asset ids to signed URLs, decode once with `createImageBitmap`
       (≤ 2048 px working copy), drop a file onto a frame → upload → place; Photos panel with the user's media and Pexels search.
6. [ ] **Filters** — WebGL2 uber-shader (colour adjustments, vignette, grain) + separable blur/sharpen, presets, Filters panel.
